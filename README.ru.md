## 📖 О книге

*Добро пожаловать в HumanBuilding* — это манифест и практическая карта для переориентации цивилизации с накопления внешнего капитала на развитие человека (HumanBuilding, HB).

Книга прослеживает, как внутреннее богатство человека — его способности, навыки, «внутренние миры» — систематически присваивалось правящими классами на протяжении истории. Она диагностирует три сходящихся кризиса позднего капитализма, разбирает прецеденты прошлых попыток построить лучшее общество и предлагает практический «Стартовый набор» для современного ЭйчБи-прогрессора.

**Структура:**
1. Основы: Недостающее уравнение
2. Исторические механизмы перенаправления внутреннего продукта
3. Диагностика: Системные пределы накопления
4. Прецеденты и исторический опыт
5. Инструментарий: Инфраструктура для ЭйчБи-прогрессорства
6. Синтез: Завершение становления
7. Приложения и ссылки

## ✏️ Как предложить правку

Исходник книги — это обычный Markdown, поэтому изменения удобно отслеживать через git:

1. Сделайте форк репозитория или создайте новую ветку.
2. Внесите правку в `book.md` (английский) или `book.ru.md` (русский). Одна логическая правка = один коммит.
3. Откройте Pull Request с кратким описанием изменения.

Опечатки, уточнения формулировок, переводы и структурные предложения приветствуются.
