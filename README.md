## 📖 About the Book

*Welcome to HumanBuilding* is a manifesto and a practical map for reorienting civilization from capital accumulation to human development (HumanBuilding, HB).

The book traces how human inner wealth — our abilities, skills, and "inner worlds" — was systematically appropriated by ruling classes throughout history. It diagnoses the three converging crises of late capitalism, examines precedents of past attempts to build a better society, and offers a practical Starter Kit for the modern HB-progressor.

**Structure:**
1. A Manifesto
2. The Theft of Our Inner Wealth
3. The Diagnosis: Three Faces of the Same Disease
4. The Precedents
5. The Tools
6. The Synthesis
7. Appendices & References

## ✏️ How to Contribute

The book's source is plain Markdown, making it easy to track changes via git:

1. Fork the repository or create a new branch.
2. Make your edit in `book.md` (English) or `book.ru.md` (Russian). One logical change = one commit.
3. Open a Pull Request with a brief description of the change.

Typos, phrasing clarifications, translations, and structural suggestions are highly welcome.
