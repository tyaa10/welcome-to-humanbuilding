## О книге

*Welcome to HumanBuilding* — манифест и практическая карта для переориентации цивилизации с накопления капитала на развитие человека (HumanBuilding, HB).

Книга прослеживает, как внутреннее богатство человека — его способности, навыки, «внутренние миры» — систематически присваивалось правящими классами на протяжении истории; диагностирует три сходящиеся crises позднего капитализма; разбирает прецеденты прошлых попыток построить лучшее общество; и предлагает практический Starter Kit для современного HB-прогрессора.

**Структура:**

1. A Manifesto
2. The Theft of Our Inner Wealth
3. The Diagnosis: Three Faces of the Same Disease
4. The Precedents
5. The Tools
6. The Synthesis
7. Appendices & References

## ✏️ Как предложить правку

Исходник книги — обычный Markdown, поэтому изменения удобно отслеживать через git:

1. Форкните репозиторий или создайте ветку.
2. Внесите правку в `book.md` (одна логическая правка — один коммит).
3. Откройте Pull Request с кратким описанием изменения.

Опечатки, уточнения формулировок, переводы и структурные предложения — приветствуются.
